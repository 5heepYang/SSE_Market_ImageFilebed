# 图床 `/api/auth/oauth/token` 返回 401 排查

> 日期：2026-08-26

## 结论

图床该接口对浏览器返回 **401**，表示：**state 已通过校验**，但向集市 `POST /api/auth/connect/token` 换票失败。

集市侧 `GetTokenbyOAuth2` 唯一会回 **HTTP 401** 的分支是：

- **`应用密钥错误`**（`app_secret` ≠ `oauth2_apps.app_secret`）

其余常见失败是 400/404（缺参、授权码过期、已使用），不是 401。

## 与「授权一圈又跳回登录」的关系（2026-08-26 复现）

浏览器 Network 顺序典型为：

1. 集市 `authorize` 成功 → 带 `code` 跳回 `image.ssemarket.cn/oauth/callback`
2. 图床 `…/api/auth/oauth/token` **红字失败**
3. 前端进 `/login` → 再拉 `login-url` → 又回到集市授权页

因此：**集市账号会话（getInfo / refresh）正常也没用**；断点只在图床换票。  
且 `authorize` 已成功 ⇒ 库里 `redirect_uri` 已与 `https://image.ssemarket.cn/oauth/callback` 一致，优先查 **secret**，不是 redirect。

## 与本机 docker ps 的关系

宿主机 `docker ps` 中的容器：

| 容器 | 角色 |
|------|------|
| `server`（sse_market_server） | OAuth IdP |
| `sse_market_db` | `oauth2_apps` / `oauth2_codes` |
| `sdpy-api` | 部署平台，不处理图床登录 |
| **无 imagebed 容器** | 图床在 **K8s 模块 `image`** |

图床 Pod 用环境变量 / `config.yaml` 里的 `IMAGEBED_OAUTH_APP_SECRET` 调 IdP；对不上就 401。

## 易误导点

`GET /api/auth/oauth/config` → 502「权限不足」：

- 图床无登录态调集市 `POST /api/auth/connect/check`
- 该路由挂在 **StrictAuth**（必须用户 JWT）
- **不代表** app 未开通；与 token 401 无直接关系

## 现网核对命令（在 API 机执行）

```bash
# 1) 库里登记的 redirect_uri / 是否启用（不要把完整 secret 打进聊天）
docker exec -i sse_market_db mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e \
  "SELECT app_id, redirect_uri, is_active, LENGTH(app_secret) AS secret_len
   FROM oauth2_apps WHERE app_id='imagebed';"

# 2) 对照图床 Pod 注入的 secret 长度/是否存在（经跳板 kubectl）
# 在 sdpy 文档约定的 gpu/跳板环境下：
# kubectl -n <ns> exec deploy/<image-prod> -- printenv | grep IMAGEBED_OAUTH

# 3) 复现一次登录时看 IdP 日志
docker logs server --tail 200 -f
```

`redirect_uri` 必须与授权请求完全一致：`https://image.ssemarket.cn/oauth/callback`（库字段是单值精确匹配）。

## 「没有响应数据」

图床 `response.Fail` 正常会返回 JSON `{"code":401,"message":"..."}`。若 DevTools 显示空 body，优先怀疑：

- 请求在 SPA 立刻 `replace('/login')` 时被取消
- 看 **Response Headers** 的 `content-length` / Preview；或用 curl 复现同一 `code`（注意 code 一次性）

## 根因确认（2026-08-26）

| 来源 | app_secret |
|------|------------|
| 库 `oauth2_apps`（改前） | 32 位 `73c82b48…` |
| 图床 `server/config.yaml` | 64 位 `42bd8af1…` |

`authorize` 200、`connect/token` 401 与此一致。对齐库或模块 env 后应恢复。
